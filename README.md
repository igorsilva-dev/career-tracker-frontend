# CareerTracker Frontend

## Run locally

```bash
npm install
npm run dev
```

## Environment

Create `.env.local`:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Pages

- `/` dashboard metrics
- `/applications` tracker add/list
- `/analysis` match and gap analysis
- `/cv-generator` tailored CV generation
